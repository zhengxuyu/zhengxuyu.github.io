一个团队只拿到一个最终奖励，怎么知道是谁做得好、哪一步做得好？本文依次介绍 LLM RL 的训练流程、经典 MARL 的信用分配方法和 LLM 多智能体训练中的新做法，并按“拿谁和谁比”归纳为一条主线。

1LLM RL 的训练流程

以 GRPO 为代表的 LLM RL，一个训练步包含以下六步。对一道题 q 采样 G 条轨迹作为一个组；每条轨迹由模型输出 a 和环境或工具的返回 o 交替组成；verifier、judge 或环境给出奖励 r；把奖励累加成回报 R；用组内均值和标准差做 baseline 得到 advantage A；最后把 A 广播给这条轨迹的每个 token，做 clipped policy gradient 更新。

2问题是什么

图 2 用一个例子说明多智能体下第 ⑤ 步的问题。

合作型多智能体任务里，环境通常只给整个团队一个回报 \(R\)。每个 agent 要用这个标量更新自己的策略，需要回答两个问题：

AGENT 之间

谁的功劳

任务成功了，是哪个 agent 的贡献？失败了，是谁的错？

AGENT 内部

哪一步的功劳

一个 agent 走了很多步，哪些动作是好的？这是单智能体里就有的时间信用问题。

如果把 \(R\) 原样发给每个 agent，会出现两个经典症状：

  • 噪声大：agent i 的梯度里混进了其他所有 agent 的随机性，团队越大，信噪比越低。
  • 搭便车（lazy agent）：有的 agent 学会了，其他 agent 就不再学，因为团队奖励已经够高。VDN 把它称为 “lazy agent” 问题，并指出它源于部分可观测。

LLM 多智能体让问题更难。 agent 常常是动态创建的，没有固定角色；轨迹很长，团队奖励被摊薄到大量 token 上；主流算法是不带 critic 的 GRPO，baseline 只能来自样本之间的比较；每条 rollout 都很贵，反事实重跑的成本很高。

3经典 MARL 的五种答案

这些方法都建立在 actor-critic 或 Q-learning 上，靠集中式的价值函数做信用分配。训练时集中、执行时分散（CTDE）是共同框架。点工作名打开原文。

Wonderful Life Utility（difference reward）

Wolpert & Tumer · Advances in Complex Systems 4(2–3), 2001
\[ \mathrm{WLU}_\eta \equiv G(\zeta) - G(\zeta^{\,\hat{}\,\mathrm{CL}_\eta}) \]

agent η 的奖励等于团队实际得分，减去把 η 的分量“钳位”成固定值 CL 之后的得分。钳位成 0 等于把这个 agent 从系统里拿掉。后来文献通称 difference reward。

“WLU overcomes much of the signal-to-noise problem of team game utilities.” p.2 §1；定义见式 (7)

COMA

Foerster et al. · AAAI 2018
\[ A^i = Q(s,\mathbf u) - \textstyle\sum_{u'} \pi^i(u' \mid \tau^i)\, Q\big(s,(\mathbf u^{-i}, u')\big) \]

用集中式 critic 代替重跑环境：固定其他 agent 的动作，只把 i 的动作边缘化掉，得到反事实 baseline。可以看作 difference reward 的可学习版本。

“it uses a counterfactual baseline that marginalises out a single agent's action” 摘要

VDN / QMIX / QTRAN

Sunehag et al. AAMAS 2018 · Rashid et al. ICML 2018 · Son et al. ICML 2019
\[ Q_{tot} = \textstyle\sum_i Q_i \quad\text{或}\quad \partial Q_{tot} / \partial Q_i \ge 0 \]

价值分解：把团队 Q 拆成每个 agent 的 Q，分解结构本身就隐含了信用分配。VDN 用求和，QMIX 用单调的 mixing 网络，QTRAN 去掉了这两种结构约束。

VDN：“learns to decompose the team value function into agent-wise value functions” · QMIX：“structurally enforce that the joint-action value is monotonic in the per-agent values” · QTRAN：“free from such structural constraints” 均为摘要

Shapley Q-value（SQDDPG）

Wang, Zhang, Kim, Gu · AAAI 2020
\[ \phi_i = \mathbb E_{C \subseteq N\setminus i}\big[v(C\cup i) - v(C)\big] \]

用 Shapley 值把全局奖励分给每个 agent：对所有联盟取边际贡献的平均，满足公平性公理。精确计算要枚举指数多个联盟。

“Shapley Q-value is able to distribute the global reward, reflecting each agent's own contribution” 摘要

MAPPO：不显式分配

Yu et al. · NeurIPS 2022 Datasets & Benchmarks

团队奖励加集中式 \(V(s)\)，不做显式的信用分解，在 SMAC、Google Research Football、Hanabi 等基准上和 off-policy 的价值分解方法相当甚至更好。说明 agent 同质、能共享参数时，显式分配并不总是必要的。

“PPO often achieves competitive or superior results in both final returns and sample efficiency.” 摘要

4LLM 多智能体训练里的六类做法

LLM 时代的主要变化是去掉了 critic。GRPO 系方法的 baseline 来自一组样本的均值，所以信用分配的问题变成了拿谁和谁比。以下按比较对象分类。

A. 不分配：只训 orchestrator

Kimi K2.5 Agent Swarm（PARL）

Kimi Team · arXiv 2602.02276, 2026

可训练的 orchestrator 加冻结的子 agent，子 agent 的轨迹不进入优化目标，被当作环境观测。奖励由三项加权：实例化奖励 \(r_{\text{parallel}}\) 防止退化成串行执行（serial collapse），子任务完成率 \(r_{\text{finish}}\) 防止只创建不完成的“虚假并行”，任务结果 \(r_{\text{perf}}\)；前两项的权重在训练中退火到 0。子 agent 这一层的信用问题被直接绕开。

“sub-agents are frozen and their execution trajectories are excluded from the optimization objective” §1

B. 广播团队奖励，组内比较整局

MAGRPO

Liu, Chen, Liang, Lyu, Amato · AAAI 2026 · arXiv

把 LLM 协作建模为 Dec-POMDP。所有 agent 共享一个联合奖励；每个 agent 每轮采样一组回答，baseline 是这组联合回报的均值；训练时集中，执行时各自独立。相当于 MAPPO 的 GRPO 版。写作和编程协作任务。

“Using a joint reward allows agents to specialize as needed to complete the task without complex prompt or reward engineering.” §3.1

MAPoRL

Park, Han, Guo, Ozdaglar, Zhang, Kim · ACL 2025

多个 LLM 先各自作答，再多轮讨论修正，联合训练。verifier 同时评价答案和讨论过程，并额外奖励纠错和有说服力的发言，这个分数就是联合训练的奖励。

“a MAPoRL verifier evaluates both the answer and the discussion … The score serves as the co-training reward” 摘要

C. 按角色设 baseline

SPIRAL

Liu, Guertler, Yu, … Jaques · arXiv 2506.24119, 2025
\[ A_{G,p}(\tau) = R_p(\tau) - b_{G,p} \]

同一个模型在零和游戏里自博弈。RAE 为每个“游戏 × 角色”维护一个 baseline，用 EMA 更新（衰减率 0.95），因为先手和后手的期望回报本来就不同。

“RAE maintains separate baselines bG,p for each game G∈𝒢 and role p∈{0,1}.” §3

MARSHAL

Yuan, Xu, … Yu, Wang · ICLR 2026
\[ A_{k} = \textstyle\sum_{j\ge k} r_j \;-\; \mathrm{mean}\big(R^{\,p}\big) \]

合作和竞争游戏都做。先把每轮之后的奖励求和，再减同角色子组 \(p\) 的均值（sum-then-normalize）。消融里把它换成 RAE，Mini Hanabi 从 54.33% 掉到 24.93%，合作游戏受影响最大。前提是角色固定、每个角色在 batch 里样本够多。

“We partition the batch of trajectories into sub-groups based on player role and apply the turn-level advantage estimator described above independently within each sub-group” p.4 §3.2

D. 反事实：换掉一个再跑

C3

Chen et al. · arXiv 2603.06859, 2026

消息级信用。在某个决策点把一条消息换成另一条，把后续流程一直跑到终局奖励，得到这条消息的无偏信用；只需重新生成决策点下游的消息。前提是下游 agent 读到的一切都写在记录里，这样记录本身就是状态，反事实可以真的执行。当前版本标题为 The Trace Is the State: Exact Credit Assignment for LLM Agent Teams。

“substitutes one message at a decision point and continues the run to the terminal reward, so its credit is unbiased, exact up to Monte Carlo error” 摘要

CCPO

Li, Tian, Chen, Zhang, Liu, Ban, Zhuang · arXiv 2603.21563, 2026

agent 级信用。比较实际联合结果和去掉某个 agent 后的结果，得到每个角色的奖励，再交给 GRPO、GSPO 或 REINFORCE++。在 Think–Solve 双 agent 的数学推理上实验：去掉 Thinker 就是让 Solver 直接答题，额外采样 solver-only 的 rollout 并用 verifier 打分；Solver 没有对应的反事实，因为去掉它就没有答案了。

“estimates an agent's marginal contribution by comparing the realized joint outcome with a counterfactual outcome” 摘要

E. 在语言空间里分配

LangMARL

Yao, Da, Liu, Fleming, Chen, Wei · EMNLP 2026

把合作 MARL 的信用分配搬到语言空间：从回放的轨迹里抽取和任务相关的因果关系，给每个 agent 稠密的文字反馈，用来改进各自的策略。适合奖励稀疏的场景。

“agent-level language credit assignment” 摘要

F. agent 内部的时间信用（单智能体工作，供参照）

MT-GRPO

Wei, Zeng, Li, … Hong · arXiv 2505.11821, 2025

多轮 agent 里利用逐轮的稠密奖励做信用分配，分别推导了 GRPO 和 PPO 的版本，比较终局、延迟、逐轮三种奖励粒度。原题 Reinforcing Multi-Turn Reasoning in LLM Agents via Fine-Grained Reward Structure and Credit Assignment。

“dense per-turn reward structures consistently outperform sparse terminal and delayed reward structures” 摘要

GiGPO

Feng, Xue, Liu, An · NeurIPS 2025

在同一任务的多条轨迹里找到相同的状态作为锚点，在锚点上做 step 级组内比较。不需要辅助模型，也不需要额外 rollout。

“Actions stemming from the same state are grouped together, enabling micro relative advantage estimation.” 摘要

一篇值得读的综述：Reinforcement Learning for LLM-based Multi-Agent Systems through Orchestration Traces（Zhang，arXiv 2605.02801，2026.05）。它把多智能体系统的运行看成一张编排事件图（spawn、委派、通信、工具调用、汇总、停止），把奖励和信用信号归到从 token 到整个团队的 8 个单位上。两个和我们相关的观察：

“explicit counterfactual message-level credit remains especially sparse in our curated pool” · “found no explicit RL training method for the stopping decision” 摘要

6一条主线

综合以上工作，可归纳为三点：

  1. 没有 critic 以后，信用分配就是构造比较组。经典方法靠学出来的 \(Q\) 或 \(V\) 提供 baseline；GRPO 系只能靠样本之间的比较。比较组里的样本在“别的因素”上越一致，算出来的信号越干净。
  2. 每种构造方式都有代价。整局比较无额外成本，但混入了队友的随机性；按角色比较要求角色固定；反事实回放信号最干净，但成本随 agent 数和消息数增长。
  3. 动态创建的 sub-agent 让前三种都失效。每个 sub-agent 的任务都不一样，没有可比的“同角色”样本；整局比较把 orchestrator 的拆分质量混进来；逐个反事实回放太贵。怎么给这类 sub-agent 构造干净的比较组，目前还是开放问题。
